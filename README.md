# 4X Cyber Attack Framework

**eXplore. eXpand. eXploit. eXfiltrate.** Each phase begins with eX.

Aubrey Finn's conceptual framework for modeling repeated adversary observation, action, and reassessment. The brief connects phase objectives to application trust boundaries, candidate telemetry, and defensive controls. It complements MITRE ATT&CK and includes proposed state transitions, qualified historical KeePass examples, and an illustrative lab-validation design.

## Research status

This repository presents a conceptual model, not a validated autonomous attack implementation. The proposed lab scenario has not been executed. No detection-performance results or new vulnerabilities are claimed. Historical CVE examples include version limits and attacker prerequisites; control effectiveness depends on configuration and telemetry coverage.

Use the model for threat-model reviews, tabletop exercises, detection hypotheses, and authorized lab planning. The white paper contains scope, limitations, and primary references.
